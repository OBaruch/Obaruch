# Possible Improvements

> **None of these changes have been applied.** The root `README.md` is kept exactly as the author wrote it, so the profile keeps its original content. This list is only for reference, and any change should be decided by the author.

## Content

1. **Inconsistent job title.** The header says *Advanced AI Engineer @ Bosch*, but *About me* says *AI Engineer II at Bosch*. Aligning the two would remove the ambiguity.
2. **Hard-coded experience count.** "4+ years" will go out of date. A start year (e.g. "since 20XX") would stay accurate longer.
3. **Education timeline.** The MBA is listed as *2025–2027, in progress*. It will need an update when it finishes.

## Rendering / external services

4. **Third-party stats cards.** The public `github-readme-stats.vercel.app` and `github-profile-trophy.vercel.app` instances are known to be rate-limited or unavailable at times. Options include self-hosting them, generating static SVGs with a scheduled workflow, or removing them. Adding a GitHub Action would add infrastructure to the repository, so it should only be done if the author wants it.
5. **Link health.** The six public project links and the website/LinkedIn links could be checked from time to time, by hand or with a link checker.

## Accessibility

6. The stats images already have `alt` text. The shields.io badges in the tech-stack section use their technology name as alt text, which is fine. The emoji in section headings are decorative and screen readers read them aloud. This is minor and a matter of style.
